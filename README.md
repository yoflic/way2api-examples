# Way2API 🚀

Simple, affordable APIs for developers worldwide.

Way2API provides APIs for:
- Email Validation API
- Domain WHOIS Lookup API
- Domain Availability API
- OTP (SMS & WhatsApp) API
- IP Lookup API

## ⚡ Quick Start

```bash
curl https://app.way2api.com/email/validate \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d "email=test@example.com"
```


👉 Get your API key: https://www.way2api.com/

🎁 Free credits available for new users.
